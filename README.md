## 📌 Overview

This repository hosts the official source code for **[bharat-kumaar.github.io](https://bharat-kumaar.github.io)**, the personal web portfolio of **Bharat Kumar**. Designed with a futuristic cyberpunk aesthetic and responsive glassmorphism interface, the site showcases engineering projects, professional certifications, work experience, technical arsenals, and downloadable developer credentials.

---

## ✨ Features & Sections

* **Hero Section:** Animated typing subtitle, interactive particle grid background, and direct CV download.
* **About & Developer Philosophy:** Overview of technical expertise spanning full-stack web architectures, AI/NLP pipelines, and real-time financial dashboards.
* **Featured Projects Showcase:** Deep dives into:
  * *NextGen Stock Analytics Dashboard*
  * *AI Chatbot Assistant (Conversational RAG)*
  * *Stock Market Predictor*
  * *AI Smart Attendance System*
  * *B-ResumeX (ATS Intelligence)*
  * *MARTFLOW Superstore (Smart Inventory)*
* **Interactive Certifications Vault:** High-resolution verified credentials from Infosys, Microsoft, Grras, DevTown, HackerRank, and MongoDB University.
* **Responsive Contact Portal:** Direct channels to LinkedIn, GitHub, and email.

---

## 🛠️ Tech Stack

* **Markup:** Semantic HTML5
* **Styling:** Custom CSS3 (CSS Grid, Flexbox, Neon glow effects, Glassmorphism backdrop-filters)
* **Interactivity:** Vanilla JavaScript (ES6+), Particles.js canvas engine
* **Hosting:** GitHub Pages (Automated static deployment on branch `main`)

---

## 💻 Local Preview

To preview the portfolio locally:

```bash
# Clone the repository
git clone https://github.com/bharat-kumaar/bharat-kumaar.github.io.git
cd bharat-kumaar.github.io

# Open in browser directly:
start index.html

# Or using Python's built-in HTTP server:
python -m http.server 8000
```
Then visit **`http://localhost:8000`** in your browser.
